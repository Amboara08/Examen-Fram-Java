# Textile — version 2

Adresse : http://localhost:8182/

Lancer avec `lancer.cmd`. Compiler et tester avec `compiler.cmd`.

Dans Eclipse : importer ce dossier comme projet Maven, puis lancer `02-textile-v2.launch` ou `com.example.textile.Application`. Java 17 minimum.

La base H2 est créée au premier lancement dans `data/textile.mv.db`. Le dossier de travail doit être la racine de ce projet. Les listes sont initialement vides.
