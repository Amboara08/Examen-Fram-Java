INFORMATIONS COMMUNES

Lancement : double-cliquer sur lancer.cmd dans le dossier du projet.
Compilation et tests d'un projet : compiler.cmd dans son dossier.
Compilation et tests des cinq projets : compiler-tout.cmd à la racine.
Arrêt : Ctrl+C dans la console de lancement ; ne pas lancer deux instances du même projet V2.
Pour un lancement dans une console avec lancer.cmd : Ctrl+C dans cette console.
Chaque adresse devient disponible après le démarrage de son projet.

Java : JDK 17 ou supérieur.
Maven : 3.6.3 ou supérieur, nécessaire pour compiler.
Eclipse : File > Import > Maven > Existing Maven Projects, puis sélectionner le dossier version-2.
Lancer la configuration .launch du projet ou sa classe Application en Java Application.
Dossier de travail : racine du projet concerné.
Arrêter toute instance utilisant le même port avant de démarrer depuis Eclipse.

Base de données de chaque projet : H2 locale, utilisateur sa, mot de passe vide.
Les chemins data ci-dessus sont relatifs au dossier du projet.
La console H2 web n'est pas activée. Aucun compte MySQL n'est nécessaire.
Les comptes de connexion sont définis dans src/main/java/com/example/<projet>/security/SecurityConfig.java.
Les comptes sont en mémoire et recréés au démarrage ; les données métier sont persistantes dans H2.
Les mots de passe sont encodés avec BCrypt par l'application.

API REST : préfixe /api, authentification HTTP Basic avec les mêmes comptes.
Paramètres métier : page /settings, accessible au compte admin.
Configuration technique : src/main/resources/application.properties de chaque projet.
Listes initialement vides : aucune donnée de démonstration automatique.
Guide détaillé : README.md de version-2. Règles métier et routes : ../EXIGENCES.md.
